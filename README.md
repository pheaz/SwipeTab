# SwipeTab

SwipeTab is a macOS-wide, trackpad-driven tab switcher.

This is the official public repository for SwipeTab releases, bug reports, feature requests, and user-facing documentation. The application source code is proprietary and maintained privately.

- [Downloads and release notes](https://github.com/pheaz/SwipeTab/releases) (when available)
- [Report an issue or request a feature](https://github.com/pheaz/SwipeTab/issues/new/choose)

When reporting a problem, include the macOS version, affected application's name and version, and steps to reproduce. Do not post passwords, private browsing data, screenshots with sensitive content, or unredacted logs.
